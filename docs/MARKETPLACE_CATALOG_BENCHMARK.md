## Принятые правила

1. OLX.kz задаёт обязательное Kazakhstan-first покрытие корневых направлений.
2. Глубина Avito используется там, где широкая группа скрывает разные задачи
   продавца или покупателя.
3. Существующие полезные ветки Marketo не удаляются; `Бизнес и оборудование`,
   `Обмен` и `Отдам бесплатно` сохранены как самостоятельные преимущества.
4. Category path определяет уже выбранный тип. Leaf не спрашивает повторно
   кузов, device type или конкретный вид услуги.
5. Справочники моделей разделены по предметной области и имеют проверяемый
   источник/дату актуальности, а fallback не заменяет основной dictionary.
