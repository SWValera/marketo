# JEVU: реальная удалённая проверка фото, 2026-09-09

**IMAGE PIPELINE: BLOCKED для полного выпуска.** Проверка Cloudflare выполнена
после отдельного разрешения пользователя. Это продолжение, а не повторная
реализация фото-этапа. Код приложения в этом продолжении не изменялся.

## Среда и изоляция

- Wrangler 4.92.0, `wrangler dev --remote`, временный edge-preview
  `jevu-photo-probe-20260909`, compatibility date 2026-05-15.
- Единственный сервисный binding — Images. Нет DB, Supabase, R2, маршрутов сайта,
  assets, пользовательских сессий или загрузки пользовательских фотографий.
- Тестовый Worker импортирует настоящий `normalizeListingImage` из
  `lib/media/server-image-normalization.ts`, `photo-contract.ts` и
  `processed-jpeg.ts`. Локальный sharp проверяет полученный JPEG, но не заменяет
  удалённый декодер. Успешный HTTP-статус без декодирования не считался проверкой.
- По [документации Cloudflare](https://developers.cloudflare.com/images/optimization/binding/)
  этот режим использует полноценную реализацию Images, а не локальную имитацию.
- Временный endpoint защищён случайным ключом и сроком действия. Ключ не входит
  в исходники/review ZIP. Процессы остановлены, временные конфигурации удалены.

## Причинная проверка HEIC

Для каждого HEIC повторены два пути: реальный нормализатор (`info` → `input`) и
тот же Images `input` напрямую, без `info`. Два отказа воспроизводятся в обоих
путях с теми же кодами 9516/9412; успешные образцы проходят оба пути.
Следовательно, просто убрать предварительную проверку не устраняет этот отказ.
Безопасность приложения ради этого не ослаблялась. После отказов последующие
поддерживаемые фотографии обрабатываются успешно.

Независимая локальная попытка декодировать `libheif/example.heic` через sharp
не выполнена: установленный libvips не содержит HEVC-декодер (11.6003). Это не
доказательство повреждения файла. Нет утверждения, что отклонённые образцы
проверены вторым независимым декодером на этом компьютере.

## Отклонённые предположения и ограничения теста

- Отказ первого временного endpoint вызван часами: локальное время отставало
  от времени Cloudflare примерно на час, и созданный локально срок уже истёк.
  В тесте срок построен по удалённому времени. Это не причина ошибки фото JEVU.
- При 3000×2000 → ширина 2560 точная высота 1706,666…; Cloudflare отдаёт 1706,
  а первоначальная проверка ожидала ровно 1707. Проверка уточнена до правильного
  диапазона округления меньше одного пикселя, не до произвольного процента.
  Исходный отрицательный результат сохранён. Повороты без масштабирования
  продолжают проверяться на точное равенство размеров.
- Настройка тестовой фикстуры quality=100 дала 24,6 МБ — за пределом проверяемого
  диапазона. Для теста 12–20 МБ использовано quality=95; качество приложения
  не менялось. Первый набор фикстур остановился до отправки этого изображения.
- Границы сервиса 20 МБ / 100 Мп / сторона 12000 остаются. 108/200 Мп и
  произвольный объём **не поддержаны**; снятие локальной проверки это не исправит.

## Оставшееся необходимое действие

Для заявленной широкой совместимости нужен проверенный резервный серверный
декодер для неподдерживаемых HEIC и больших исходников. Текущий 128-МБ Worker
нельзя считать безопасной средой для полного RGBA-декодирования 100–200 Мп.
Подключение другого сервиса/вычислительного окружения и допустимая стоимость
требуют отдельного согласования; настоящим разрешением был охвачен только
временный тест без платных подключений. Неполный путь на jevu.kz не опубликован.

REAL iOS PWA: **NOT VERIFIED**. Полный SQL-прогон: **NOT VERIFIED**, как в
предыдущем отчёте. 352 локальных теста, typecheck и build относятся к предыдущему
продолжению и в этом диагностическом этапе заново не запускались.
